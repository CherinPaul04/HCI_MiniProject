StudyDeck HCI — Multimodal Accessible Flashcard Platform

A multimodal, accessible flashcard study platform engineered for Human-Computer Interaction (HCI). Supports **Eye-Gaze Tracking (WebGazer)**, **Voice Control (Web Speech API)**, **Switch-Key Navigation (Motor Impairment Access)**, **Text-To-Speech (TTS)**, and **Instant PDF Extraction**.
